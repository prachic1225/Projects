This project explores the Netflix Movies and TV Shows dataset to uncover insights about Netflix's content library. Using Python and data visualization techniques, we analyze trends in content addition, genres, countries, ratings, and durations.

**Objectives:**

1. Understand the structure of the Netflix dataset.
2. Clean and preprocess the data.
3. Analyze trends in Movies vs TV Shows.
4. Identify top countries producing Netflix content.
5. Analyze content ratings.
6. Discover popular genres.
7. Visualize yearly content additions.
8. Generate business insights.

**Technologies Used:**
1. Python
2. Pandas
3. NumPy
4. Matplotlib
5. Jupyter Notebook
